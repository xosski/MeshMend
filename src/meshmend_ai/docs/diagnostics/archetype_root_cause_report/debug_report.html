Root cause

  1. The humanoid body originates in procedural primitive builders, not in a race-specific anatomical or armor asset library.
  2. Cube/cylinder/capsule/ellipsoid primitives survive because they are the actual production part geometry. The code names them component-library parts, but the library is generated from primitives at runtime.
  3. High Elf requests affect the concept profile, metadata tags, and some proportions, and route to _build_high_elf_category_mesh. They do not replace the body generator with authored High Elf sculpt assets.
  4. Dwarf Warrior, Orc Brute, and Human Knight are not implemented as staged shape-language branches in CharacterArchetypeGenerator or ShapeLanguageEngine, so their silhouettes are generic humanoid layouts with different labels/details.
  5. Silhouette validation is not a semantic vision critic. It uses tags, bbox ratios, and simple projected metrics, so it can pass a mesh whose silhouette is still mannequin-like to a human.
  6. Faction-specific assets are mostly procedural branches and metadata tags, not curated faction/race asset libraries.
